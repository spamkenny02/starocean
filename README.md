# Star Ocean FR — suppression du S-DD1

Projet de recherche et de portage du hack 96 Mbit vers la traduction française BadCompany.

## État vérifié

Un premier prototype démarre avec le S-DD1 désactivé et atteint la scène jouable dans la maison après 24 000 images émulées. Ses tables sont encore limitées au parcours d’ouverture relevé : **le jeu complet n’est pas couvert**.

Le travail en cours consiste à élargir les tables, couvrir les autres routines/transferts et vérifier les combats et sauvegardes. Les versions seront distinguées des résultats réellement testés.

Les ROMs complètes et les données graphiques extraites ne sont pas publiées dans ce dépôt. Les scripts nécessitent les fichiers d’entrée fournis séparément par l’utilisateur.
